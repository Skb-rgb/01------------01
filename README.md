# HOLO — Demo de apertura de sobres

Demo interactiva creada con HTML, CSS y JavaScript puro, inspirada en la referencia audiovisual enviada por el usuario. Incluye un sobre animado, revelación de cinco cartas, confeti, selección de cartas y reinicio.

## Publicación en GitHub Pages
1. Crea un repositorio público en GitHub (por ejemplo `holo-pack-demo`).
2. Sube `index.html` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment** selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/(root)` y guarda.
6. La URL normalmente será `https://TU-USUARIO.github.io/holo-pack-demo/`.

## Personalización
En el array `characters` del archivo `index.html` puedes cambiar nombres, emojis, colores y tipos. Para un acabado 3D fotorrealista como el original, sustituye los emojis por renders PNG/WebP transparentes o modelos GLB y refina el material del sobre y la animación de apertura.

No se requieren dependencias, compilación ni alojamiento de backend.
